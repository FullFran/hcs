# HCS v0.1.0-draft.4

Fourth pre-release of HCS 0.1. The specification documents, schemas and
conformance cases are unchanged from draft.3; instance documents keep
`"hcsVersion": "0.1"`. This release adds the TypeScript reference SDK
([ADR-0029](../adr/0029-reference-sdk-in-typescript.md)). See "How to pin HCS" in the README.

## What is new

- **README rule 2** now reads: types are derived from the schemas; the reference
  implementation in `sdk/ts/` is hand-written and measured against `conformance/`
  like any harness.
- **`@fullfran/hcs-sdk` 0.1.0-draft.4**: catalog validation, package archives,
  capability ids, HCS-0003 resolution, HCS-0004 lifecycle and generations,
  HCS-0005 authority, HCS-0006 errors, HCS-0007 signing and verification, and the
  HCS-0008 projection core with an engine-neutral `EngineAdapter`. Distribution
  specifics (host profile, grantable permissions, detail-key prefix) are caller
  parameters. The host lock is an SDK extension (`x-hcs-sdk-host-lock/0.1`) until
  HCS defines host-owned settings (OQ-0008-2).
- **Measured conformance of the SDK**, 0 fail: authority 14, document 54,
  integrity 3, resolution 33, distribution 37, projection 41; host-level cases
  stay pending.
