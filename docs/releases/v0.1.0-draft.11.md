# HCS v0.1.0-draft.11

Artefact release. The specification, schemas and conformance cases are those of draft.10; instance
documents keep `"hcsVersion": "0.1"`. The SDK changes only its version number.

The artefact can now be vendored on Windows: one conformance case had a reserved device name, and
one Markdown link in it pointed at a file that is not in the artefact (#100).

## Changes a host must make

None in code. A consumer that selects cases by path renames
`conformance/cases/HCS-0001/HCS-0001-R019/invalid/nul.json` to `hidden-nul.json` in its own
records (baselines, divergence lists). The case content is unchanged.

## What changed

### Artefact

- The HCS-0001-R019 case `invalid/nul.json` is now `invalid/hidden-nul.json`. `NUL` is a reserved
  device name on Windows: Git for Windows could not check it out, and unpackers that refuse such
  names rejected the whole release (#100, #103).
- `tools/build_release.py` refuses any path Windows cannot create, so a release cannot ship one
  again.
- `tools/build_release.py` rewrites Markdown links whose text holds a code span. The link to
  `tools/consumer-kit/` in `conformance/README.md` stayed relative before, and was broken in a
  vendored copy; it now points at the tag.

### Specification and conformance

- No change: 518 cases, 159 requirements, as in draft.10.

### SDK

- Version 0.1.0-draft.11. No API change.
- The SDK still requires Node 24 or later.
