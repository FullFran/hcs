## What changed

- **SDK keeps the executable bit** (#57). Package files with the owner execute bit are
  archived as 0755 (others 0644), extracted with that mode and sealed as 0555. Packages
  without executable files produce the same bytes as with draft.4; packages with them get a
  new `contentHash`. Member modes are not specified by HCS yet (see #56).
