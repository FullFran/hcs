# HCS v0.1.0-draft.10

Artefact release. The specification, schemas and conformance cases are those of draft.9; instance
documents keep `"hcsVersion": "0.1"`. The SDK changes only its version number.

The artefact now carries `skills/hcs/`, an Agent Skill that tells an agent when to apply HCS, the
principles a harness design must keep, and how to record a divergence. It ships beside the specs
it cites, so a consumer that vendors this release gets the skill of this exact version.

## Changes a host must make

None. A consumer that wants its agents to use the skill points its agent's skill directory at
`vendor/hcs/0.1.0-draft.10/skills/hcs` (for example with a symlink) and moves it on each upgrade.

## What changed

### Artefact

- New `skills/hcs/SKILL.md` and `skills/hcs/references/spec-map.md` (#98). The skill cites
  requirement IDs and defers to the specs when they disagree. Its frontmatter uses only Agent
  Skills fields.
- `tools/build_release.py` includes `skills/`; the archive goes from 564 to 566 files.
- CONTRIBUTING: a change to a principle or requirement the skill cites updates the skill in the
  same pull request.

### Specification and conformance

- No change: 518 cases, 159 requirements, as in draft.9.

### SDK

- Version 0.1.0-draft.10. No API change.
- The SDK still requires Node 24 or later.
