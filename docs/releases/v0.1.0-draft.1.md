# HCS v0.1.0-draft.1

First pinnable snapshot of HCS. It is a **pre-release**: every document is
Draft, no host passes a profile yet, and the next `draft.N` may change any
document incompatibly (HCS-0000 section 5). It exists so hosts can vendor one
exact, checksummed copy of the schemas, cases and runner instead of reading
`main`. See "How to pin HCS" in the README.

Instance documents keep `"hcsVersion": "0.1"`.

## Schemas

`urn:hcs:schema:hcs-000{0..7}:<name>:0.1` (common, catalog-manifest, capability,
resolution, lifecycle, authority, error, signed-catalog) and
`urn:hcs:schema:conformance:case:0.1`. HCS-0008 has no schema of its own; its
cases use the case schema.

## Conformance

- 215 cases: 68 document, 3 integrity, 33 resolution, 7 authority,
  37 distribution, 23 projection, 44 host.
- The reference runner executes the 171 non-host cases (all pass) and reports
  the 44 host cases `pending`; a system-under-test interface is tracked in #20.
- Profiles: CORE-0 (38 requirements) and DISTRO-1 (22, builds on CORE-0), both
  Draft. No host claims either.

## Changes since the previous snapshot

- First release; no previous tag.
- Examples and cases use the neutral extension prefix `x-example-*` instead of
  a product name. Extension members are ignored by HCS (HCS-0000-R003/R004), so
  verdicts are unchanged.
- HCS-0000 section 5 defines `0.1.0-draft.N` pre-releases.
